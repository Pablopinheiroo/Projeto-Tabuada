# Projeto Tabuada

**Aprender matemática pode ser uma aventura.**

O Projeto Tabuada é um jogo educativo para praticar multiplicação, acompanhar a evolução e transformar as contas mais difíceis em novos desafios. A proposta é tornar o estudo mais leve, interativo e divertido, tanto para quem está começando quanto para quem quer ganhar velocidade e confiança.

## Jogue

**[Abrir o Projeto Tabuada](https://pablopinheiroo.github.io/Projeto-Tabuada/)**

Crie seu perfil, escolha um modo e comece a praticar. Compartilhe o link com amigos para jogar e comparar resultados.

## O que você encontra no jogo

- **Treinamento livre:** escolha as tabuadas e pratique no seu próprio ritmo.
- **Treinar minhas dificuldades:** uma lista personalizada com as multiplicações que você erra, marcou como difíceis ou demora mais para responder. As contas continuam em revisão até alcançar o domínio definido pelo jogo.
- **Modo aventura:** avance por fases, complete objetivos e desbloqueie novos caminhos.
- **Desafios e duelos:** convide outros participantes, acompanhe as partidas e confira a classificação.
- **Torneio mensal:** dispute posições no ranking e tente melhorar seu resultado.
- **Perfil e estatísticas:** acompanhe acertos, erros, tempo de resposta, evolução e pontos que merecem mais atenção.
- **Conquistas e coleção:** desbloqueie medalhas, títulos, avatares e recompensas virtuais.
- **Trilhas sonoras originais:** cada ambiente tem músicas próprias, com estilos diferentes para a entrada, o estudo, a aventura, os desafios e os torneios.

## Como começar

1. Acesse o jogo pelo link acima.
2. Crie seu perfil com um nome de usuário e uma senha exclusiva para o jogo.
3. Escolha Treinar, Modo Jogo, Desafio ou Torneio.
4. Consulte suas estatísticas para descobrir o que já domina e o que precisa praticar novamente.

## Objetivo

O objetivo do Projeto Tabuada é incentivar a prática constante da multiplicação, valorizar o progresso individual e ajudar cada participante a aprender também com os próprios erros.
